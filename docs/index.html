mnKord – free MIDI chord plugin for Windows (VST3)

One key. A whole chord.

Play a single note and mnKord sends the full chord to your synth. Map any key to any chord, with templates, chord symbols, velocity layers and 31 ready-made presets.

How it works

mnKord is a MIDI effect. It makes no sound itself: it sits in front of your synth.

  1. Play one key

    Your MIDI keyboard sends a single note.

  2. mnKord expands it

    The key is looked up in the current preset and becomes a chord.

  3. Your synth plays it

    Put any synth after mnKord. All other MIDI passes straight through.

Made for fast chord playing

Everything you need to turn one finger into a full harmony, and nothing that gets in the way.

  • Any key to any chord

    Click an INPUT key, then the chord tones. Or right-click for triad and seventh templates.

  • Chord symbols

    Type Dm9/G, Bbmaj7 or C6/9 and the chord is voiced for you.

  • Velocity layers

    Play softly for one chord, hit harder and a fuller one takes over.

  • Scales

    Limit the keyboard to a scale and fill the whole preset with its triads or sevenths in one click.

  • 31 presets, and a real browser

    Pop, jazz, soul, cinematic, dark, quartal. Search, tags, favourites and your own presets.

  • Learn, undo, transpose

    MIDI learn from your controller, undo and redo, copy a whole octave, transpose keys or chords.

Everything in the box

The full feature list of mnKord 1.6.0.

Building chords

  • Map any of the 128 MIDI keys to a chord of your own.
  • Click the chord tones on the CHORD keyboard, or right-click an INPUT key for chord templates.
  • Type a chord symbol (for example Dm9/G) to replace the selected chord; the name of the chord is shown for the selection.
  • Invert a chord up or down with a right-click on a CHORD key.
  • Copy the chords of a whole octave one octave up or down.
  • Fit a chord to the selected scale, or clear it, from the right-click menu.

Playing

  • Velocity layers: a soft layer for any velocity and a hard layer from velocity 80, 90, 100, 110 or 120.
  • MIDI learn: play a key on your controller to select or create its mapping.
  • Overlapping chords share notes (reference counted), so notes are not cut off or left stuck.
  • The sustain pedal and all other non-note MIDI (CC, pitch bend, aftertouch) pass through to your synth.
  • VST3 plugin and a Standalone program.

Presets

  • 31 read-only factory presets, and your own presets saved as files shared by every project.
  • A preset browser with group, author and style columns, search and favourites.
  • Preset metadata: name, group, author and style tags.
  • XML export and import; import accepts a single preset or a whole bank file.
  • The host program list mirrors the preset list (128 fixed programs), so program changes and automation pick the same presets.
  • A project stores the preset you used, with your edits, so it sounds the same on another computer.

Workflow

  • Undo and redo for every mapping edit (Ctrl+Z, Ctrl+Y).
  • Transpose the whole preset, or only its chords, by a semitone or an octave.
  • Restrict the keyboard to a scale and fill a preset with its triads or seventh chords.
  • A dark, flat window with two keyboards and the version of the plugin under the title.
  • Free and open source under the AGPL-3.0.

Chord symbols, templates and scales

Type a chord symbol in the field above the CHORD keyboard and press Enter. Any root works (C, F#, Bb, ...), and a slash adds a bass note.

Chord symbol endings

Put one of these after the root note, for example Dm9/G. A slash and a note name add a bass note (G/B).

System requirements

  • Windows 10 or 11, 64-bit (installer for the VST3).
  • A DAW or host that loads VST3 plugins.
  • A MIDI keyboard or controller (or the DAW's piano roll) to play the keys.
  • A synth or sampler after mnKord, because mnKord itself makes no sound.
  • Linux: build from the source code (instructions in the repository). macOS is not supported yet.

Frequently asked questions

What is mnKord?

mnKord is a free MIDI chord plugin (VST3) for Windows. You play one key and it sends a whole chord to your synth. Every key can have its own chord, set with templates, chord symbols or by clicking the notes.

Is mnKord free?

Yes. mnKord is free software under the GNU Affero General Public License v3.0, and the source code is open on GitHub.

Does mnKord make sound by itself?

No. It is a MIDI effect: it turns one note into a chord, and the synth or sampler after it plays the sound. Put it on an instrument track, before your synth.

Which operating systems does it run on?

There is an installer for Windows 10 and 11 (64-bit). On Linux you can build it from the source code. macOS is not supported yet.

Which DAWs can I use it in?

mnKord is a standard VST3 plugin, so a DAW that hosts VST3 plugins on Windows can load it. How MIDI is routed to the next plugin differs between DAWs; the user guide has the steps.

How do I make my own chord?

Click a key on the INPUT keyboard, then click the notes on the CHORD keyboard. You can also right-click an INPUT key for chord templates, or type a chord symbol such as Dm9/G in the field above the CHORD keyboard.

Which chord symbols can I type?

Triads, suspended, power chords, sixths, sevenths, ninths, add9, altered sevenths (7b9, 7#9), 6/9, quartal chords, and slash chords with a bass note, for any root note. The full list is on this page.

What are velocity layers?

A key can have a second, hard layer with its own chord. It plays instead of the soft layer when you hit the key at least as hard as the threshold you choose (80, 90, 100, 110 or 120).

Where are my presets saved?

Your presets are files in Documents\MNAudio\mnKord\User, shared by every project. A DAW project also stores the preset it used, with its edits, so it sounds the same on another computer.

Who made mnKord?

mnKord is made by Miklós Németh as a vibecoding project: the idea, the taste and the decisions are his, and the code is written together with an AI.

Get mnKord

Free, with the source code open. The Windows installer is the quick way in.

Windows (64-bit)

  1. Download mnKord-1.6.0-win-x64-setup.exe from the latest release.
  2. Run it. The VST3 goes to Common Files\VST3\MNAudio.
  3. Rescan plugins in your DAW and put mnKord on an instrument track, before your synth.
